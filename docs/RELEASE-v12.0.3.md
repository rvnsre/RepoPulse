## RepoPulse 12.0.3

- Use **Next** in the Advanced footer to browse up to three eligible repositories at a time. The counter shows how many remain.
- Manual browsing remembers the repositories it displayed across clicks, Undo, and app restarts. The final page shows only the projects that are left, and the button stops at the end.
- The catalog still requires 50,000 stars per repository. It can handle over 10,000 records when GitHub has that many qualifying results. The app displays real GitHub repositories and counts.
