## RepoPulse 12

The desktop panel uses the RSS dark design, with the hidden screen-edge handle, a compact Dynamic Island, and the expanded repository and command view. Use the Island button in the expanded window to switch to the compact view. Install opens the repository's release page, shows its README when no releases are published, or copies a verified package command.

RSS+ uses the Gumroad monthly membership at [the checkout page](https://ravansariyev.gumroad.com/l/rss). In the app, open RSS+ and enter the license key from the Gumroad receipt. Activation verifies the product, tier and membership status directly with Gumroad. The key is encrypted with OS-provided storage when available. Verification recurs while the app is running, with a 24-hour maximum offline allowance from the last successful check.

RSS+ adds a 100-repository watchlist, OPML export of GitHub release feeds, and a Markdown digest with cached release metadata. The watchlist stays local. It is preserved when a subscription expires and becomes accessible again after activation.

Includes Windows x64 Setup and Portable EXE, macOS Apple Silicon DMG and ZIP, and Linux x64 RPM, DEB and AppImage. Packages are unsigned. The release includes SHA-256 checksums.
