## RepoPulse 12.0.4

- Compact Island rotates among eligible projects every five seconds while it is visible. It keeps a three-line description visible, automatically shrinks long text, and shows the full description on hover.
- Advanced displays four repositories in a 2 × 2 grid when there are enough results. Next continues to remember earlier pages and stops when the catalog is exhausted.
- The pointer must touch the visible black indicator to reveal the island. Its surrounding transparent area no longer activates hover.
- The island transition and card changes use eased motion and respect reduced-motion preferences.
