# RepoPulse product plan

## 10.0.0 delivered scope

- Redesigned discovery cards, larger text and a separate sidebar workspace.
- Stable leave/idle deadlines, fresh annotations without stale drafts and safe monitor geometry.
- Working loopback preview, 104 unit tests and expanded native regression coverage.
- Pointer-aware compact/expanded island with leave and idle collapse, hover reveal, protected editing and focus sessions.
- Configurable motion character and safe hover growth, readable text scaling and accent/card controls.
- Private annotations, collections, reading queue, library search and bulk operations.
- Three-project comparison, local Insights and command palette.
- Validated workspace transfer and safer persistence.

See [the implemented inventory](ULTIMATE-v0.5.md) for the individually traceable controls and corrections. See README.md for current behavior.

## Remaining release work

- Native transparency, multiple monitors, OS scaling and accessibility acceptance on real Windows, macOS and Linux devices.
- Review and commit the dependency lock produced by CI.
- Select a distribution license and configure platform signing.
- Attach durable installer assets to published releases.
- Browser-store publication and an explicit-consent aggregate browser bridge.
- Localization, signed updates and optional local-language-model explanations.

None of these remaining items is represented as a shipped v10 feature.
