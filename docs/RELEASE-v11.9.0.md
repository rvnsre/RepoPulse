RepoPulse has a new desktop interface inspired by the WinUI 3 design language. Discover, repository cards, source tabs, workspace navigation, settings and notifications share a restrained palette and consistent controls. Appearance follows the system by default and also offers explicit Light, Dark and High Contrast options.

RepoPulse continues to use Electron and retains its discovery, keyboard and accessibility settings, local data and platform packages.

- Windows x64: Setup and Portable EXE
- macOS Apple Silicon: DMG and ZIP
- Linux x64: RPM, DEB and AppImage

The packages are unsigned. SHA256SUMS.txt covers all seven download files.
