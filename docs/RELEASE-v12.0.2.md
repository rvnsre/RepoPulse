## RepoPulse 12.0.2

- Hidden Mode uses a 68 × 5 indicator. Hover or click to reveal the 520 × 74 Dynamic Island.
- The Compact Island shows the current repository owner and recent release context. Its separate link opens the release in GitHub.
- Advanced shows two columns of distinct repositories on a 920 px charcoal panel. The footer identifies the current operating system.
- Open the GitHub RSS+ brand to access commands, settings, the library, and membership. Right-click a repository to open its Overview with install and clone commands.
